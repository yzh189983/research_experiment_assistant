核心结论速览 / ABSTRACT

这是一个把科研想法落地为可复现实验并自动收尾的本地工作台。它不替你做科研判断，而是把「写代码、连服务器、盯日志、汇总结果、管理账号与查看运行态」这些重复劳动接管掉。

  • 全链路自动化：创新点 → 方案 → 代码 → SSH 部署 → 监控 → 总结
  • 本地可控：数据、代码、密钥都留在自己机器上，自带网页服务器终端
  • 多账号协作：自助注册、登录改密、个人主页保存科研工作者档案
  • 运行态可视：服务器任务 step 进度 + SSH 扫描手动 Python 脚本
  • 人机协作：每个阶段都能介入修改，方案与代码均可编辑
  • 定位错位竞争：不做“通用 AI 科学家”，做“个人科研者的中文 AI 实验台”
01

项目概述

Overview

做实验的瓶颈，往往不是想法，而是把想法变成一次干净、可追踪、能写进论文的实验：写脚本、配环境、连 GPU 机器、半夜盯日志、最后还要从一堆输出里拼出结论。这款工具把这条链路完整接了起来。

03

核心能力

Capabilities

Web 实验台

六页式管理界面：实验、服务器、终端、个人主页、设置与登录注册。期刊排版风格，可打印成论文式报告。

命令行 rekit

auto 一条命令跑完全流程；plan/code/run/watch/report 分步可控。服务未起自动拉起。

网页服务器终端

xterm.js + WebSocket + paramiko 真 PTY，支持 vim / htop，自动注入 UTF-8 locale，中文不乱码。

本地文稿读取

拖入即可解析成创新点，自动填标题。docx 用标准库解，pdf 走 pypdf，GBK 中文文本也不乱码。

实时监控与指标

自定义 @@METRIC 协议 + 常见 loss/acc 兜底解析，手写 canvas 折线图，无 CDN 依赖。

结构化总结与核验

LLM 优先、规则兜底。输出假设判定、异常、局限、下一步与论文段落，并把报告数字逐条回查指标、区分实测与推断，导出 Markdown / Word / PDF。

账号与个人主页

自助注册、登录改密、session + API Token 双通道；个人主页保存科研方向与学术链接，数据按账号隔离。

服务器运行态

已添加服务器直接显示本项目任务的运行状态与 step 进度，5 秒轮询，不用切回实验页。

手动脚本扫描

SSH 读取远程进程，发现手动跑的 Python 脚本；显示中文路径、PID、父进程、CPU/内存，15 秒短缓存。

GitHub 代码推送

设置页配置 fine-grained Token（加密、按账号隔离），实验页一键把任意 run 的代码快照推到自己的仓库；推送前扫敏感信息，成功后报告里的 commit 变成可点击链接。

可访问性与国际化

右上角一键切换中英文（350 条文案映射，动态内容自动翻译）；skip link、焦点描边、Esc 关弹窗、图标 aria-label 让键盘与读屏用户可用；配色对比度全部达到 WCAG AA。

统计与 AI 自审

多 run 自动算 mean ± std / 95% CI，Welch t 与 Mann-Whitney U 给 p 值；总结后再跑一轮「审稿人」模型，六维打分并列出待补实验，帮结论站得住。

失败自动诊断

失败时从日志尾部与退出码命中 12 类错误签名（CUDA OOM / exit 137 / 缺依赖 / 路径错等），给出证据行号和降 batch、装依赖等修复建议。

协作与通知

带密码/有效期/脱敏的分享链接与访客批注；实验标签、归档、搜索与全局时间线；完成/失败/判据未通过时 Webhook 推送到企业微信或钉钉。

Workspace

06

竞品定位

Positioning

同类产品分三层。全自动 AI 科学家与实验管理平台两端都很拥挤，而“面向个人、接自己服务器、人可介入、中文科研档案”的中间地带仍留有空间。

表 2　三层竞品格局（截至 2026-11）
层级代表项目与本项目关系
全自动 AI 科学家Sakana AI Scientist（已发 Nature 2026）、Google Co-Scientist、MIT Agent Laboratory流程相似，但目标是自动写论文、不接用户自己的服务器；正面竞争无优势
本地研究工作台OpenResearch（~3.5k star，活跃）、AutoLab（近乎停更）形态最接近：本地优先 + SSH + agent 跑实验。OpenResearch 是最强对手
实验管理 / GPU 云W&B、ClearML、Experimaestro、RunPod / AutoDL只管“跑”与追踪，不做“创新点 → 方案代码”；网页终端是标配而非差异
定位建议 / POSITIONING

不要叫“通用 AI Scientist”——那是与 Sakana、Google 正面硬碰。更稳的定位是“个人科研者的中文 AI 实验台 / agentic lab notebook”：把差异化压在本地私有、接自己的 SSH、人全程可介入、报告可直接读写，并以中文文稿输入与论文式档案形成错位。
