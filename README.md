# 科研实验助手

把「一个研究想法」变成「一份跑完的实验报告」的本地工具：写下创新点，自动生成方案与代码，通过 SSH 部署运行，全程盯日志和指标，跑完自动总结并核验结果。

```
创新点 → 实验方案 → 可执行代码 → SSH 部署运行 → 实时监控 → 自动总结
```

## 启动

```bash
# 1. 安装依赖
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt

# 2. 启动服务
.venv/bin/python app.py
# 或
./rekit server start
```

打开 `https://127.0.0.1:7788`（自签证书，浏览器点「继续访问」）。首次启动自动创建 `admin`，初始密码用 `./rekit admin-password` 查看；也可在登录页自助注册。

建议按顺序配置：

1. **设置**页填 LLM 的 `base_url / api_key / model`（任意 OpenAI 兼容接口），点「测试连通性」
2. **服务器**页加一台 SSH 主机，点「测试连接」
3. 回首页写创新点、创建实验

不配 LLM 也能跑，系统会生成占位方案和代码用于验证链路。也可以完全用命令行：`./rekit auto -i @想法.md`。

## 核心功能

**实验流水线**

- 创新点支持拖拽 `.md/.txt/.tex/.csv/.docx/.pdf` 文稿导入
- 方案拆解为假设、数据集、指标、基线、消融、判据与风险；代码自动生成，可在页面直接修改
- SFTP 上传、建 venv、装依赖、`nohup` 后台运行；每 3 秒增量读日志、查进程、采 GPU、解析指标
- 运行结束自动聚合指标、逐条判断假设、输出结论与论文段落，并把报告里的数字回查到指标与日志

**可信与规范**

- Git 快照谱系：每次运行锁定 commit，支持 Diff / 恢复 / Fork
- 结果核验、预注册判据锁定、多 run 统计与显著性检验、失败自动诊断
- AI 五档可信分级与逐句证据、AI 自审、回归评测样例、白名单工具沙箱与全量审计
- 种子 / `pip freeze` / `nvidia-smi` 环境固化

**项目协作与卡卡**

- 项目 / 工作区与 owner / editor / viewer 角色，数据按账号隔离
- 卡卡智能体：实验前写脚本、实验中盯异常、实验后总结；点右下角形象弹出侧边栏多轮对话（带历史），可在设置里单独配模型
- 项目群聊可发消息，输入 `@` 自动弹出可提及对象（卡卡 + 项目成员，支持键盘上下选 / 回车确认 / 打字过滤）；`@卡卡` 提问会基于实验记录回答，进度与结果自动播报
- 数据集收集：按年份范围优先检索 CCF-A / 中科院一区论文，提取数据集并给出 Hugging Face / Zenodo 文件级下载链接
- 带密码 / 有效期 / 脱敏的只读分享链接，访客可留批注

**卡卡三阶段怎么用**

- 实验前：实验页顶部卡卡工作台点「让卡卡写实验方案 / 写实验脚本」；右下角卡卡形象可弹出侧边栏，进行带历史的多轮对话
- 实验中：run 为 `running` 时工作台显示监控小结与「刷新卡卡监控」，右侧栏实时显示日志、指标曲线、GPU 与进程
- 实验后：run 已 `finished` 但还没结论时，工作台只给一个「让卡卡总结这次结果」，点它生成带证据的结论、判据核验与论文段落，并播报到项目群

**演示数据（无需 SSH / LLM 也能体验）**

```bash
python3 tools/demo_running.py --reset    # 造一个「运行中」实验，体验监控面板与卡卡盯梢
python3 tools/demo_finished.py --reset   # 造一个「已跑完、待总结」实验，体验实验后总结
# 两者标题均以 [演示] 开头、放在个人项目；--reset 会删旧建新（实验编号递增）
```

**效率工具**

- 网页终端（真 PTY，支持 `vim` / `top` / `tail -f`）
- 报告导出 Markdown / Word / 打印页（浏览器另存为 PDF）
- 命令行 `rekit` 完成建实验、生成、运行、日志、报告全流程；`./rekit server restart` 重启服务
- 缩略卡片工作台、批量实验与对比、全局时间线、通知告警
- 界面右上角一键切换中英文
